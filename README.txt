Formatted ListBox 1.0 demo

Run modDemo.DemoNow to open the form.

The form creates a clsFormattedListBox inside an MSForms Frame, fills it with eight three-column rows, applies per-character bold and color formatting, and reports selection changes. Use the buttons to repopulate, add, select, clear, or toggle bold formatting. Double-click a row to see its Tag value.

Source exports are included beside this workbook.
